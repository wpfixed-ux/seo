# AI Marketing Assistant - Алгоритм Работы

## 📋 Полный workflow системы

### 1️⃣ Создание персонализированного оффера

#### Шаг 1: Выбор аудитории
```
Админ панель → Offers → Create New

Варианты:
✅ Выбрать сегмент (группа клиентов)
✅ Выбрать конкретного клиента
✅ Выбрать триггер (автоматически)
```

#### Шаг 2: Настройка оффера
```
1. Название кампании
2. Тип: promotional | reactivation | cross_sell | loyalty | birthday | holiday
3. Выбор товаров (опционально)
4. Параметры скидки
5. Выбор AI провайдера (Claude/OpenAI/Kimi)
```

#### Шаг 3: Генерация с AI
```
Для сегмента:
- AI генерирует базовый оффер
- Опция: "Персонализировать для каждого клиента"

Персонализация:
┌─────────────────────────────────────────┐
│ Для каждого клиента в сегменте:        │
│ 1. Анализ истории покупок              │
│ 2. Определение предпочтений            │
│ 3. Генерация уникального текста        │
│ 4. Генерация баннера с AI              │
│ 5. Подбор товаров из истории           │
│ 6. Расчет оптимальной скидки           │
└─────────────────────────────────────────┘

Результат:
- Таблица персонализированных оферов
- Предпросмотр для каждого клиента
- Оценка релевантности (AI scoring)
```

#### Шаг 4: Предпросмотр
```
Отображается список:

┌──────────────────────────────────────────────────┐
│ Клиент | Заголовок | Товары | Скидка | Preview  │
├──────────────────────────────────────────────────┤
│ Иван П.│ Новинки..│ 3 шт   │  15%   │ [👁️] [✏️]│
│ Мария К│ Возвраща.│ 5 шт   │  20%   │ [👁️] [✏️]│

[👁️] - Посмотреть полный оффер
[✏️] - Редактировать вручную
[✅ Утвердить всё] [📤 Отправить]
```

### 2️⃣ Отправка кампании

#### Выбор метода отправки
```
[ ] Email (рекомендуется для больших объемов)
[ ] Telegram (быстро, для подписчиков)
[ ] Оба канала
```

#### SMTP Throttling (контроль отправки)
```
Настройки:
- Emails per hour: 20 (настраиваемо)
- Priority system (VIP клиенты первыми)
- Retry logic (3 попытки при ошибке)

Алгоритм:
┌─────────────────────────────────────┐
│ 1. Все офферы → Email Queue         │
│ 2. Сортировка по priority           │
│ 3. Cron каждые 3 минуты             │
│ 4. Отправка N писем (throttling)    │
│ 5. Обновление статусов              │
│ 6. Retry для failed                 │
└─────────────────────────────────────┘

Status tracking:
- queued → sending → sent
- queued → sending → failed → retry
- opened / clicked / converted
```

#### Расписание отправки
```
Варианты:
- 🚀 Сейчас (добавить в очередь с high priority)
- 📅 По расписанию (указать дату/время)
- ⏰ Оптимальное время (AI определяет лучшее время для клиента)
```

### 3️⃣ Автоматические триггеры

#### Типы триггеров (создаются автоматически):

**🎂 День Рождения**
```
Условие: birthday = сегодня
Когда: За N дней до ДР (настраиваемо)
Что: Персональная скидка 15%
Товары: Из истории покупок клиента
```

**😴 Неактивность**
```
Условие: last_order_date < 30 дней назад
Проверка: Ежедневно
Что: "Мы скучали!" с скидкой 10%
Товары: Популярные + из категорий клиента
```

**🎉 8 Марта (женщинам)**
```
Условие: gender = 'female' AND date = 03-08
Когда: За 3 дня до праздника
Что: Специальное предложение 20%
Товары: Подарки, украшения, косметика
```

**🎄 Новый Год (всем)**
```
Условие: date = 25-31 декабря
Когда: За 7 дней до НГ
Что: Новогодняя распродажа 25%
Товары: Весь ассортимент
```

#### Процесс работы триггеров:
```
Cron ежедневно:
┌─────────────────────────────────────────┐
│ 1. Проверить все активные триггеры     │
│ 2. Найти клиентов под условия          │
│ 3. Проверить: не получал ли недавно    │
│ 4. Сгенерировать персональный оффер    │
│ 5. Добавить в email queue              │
│ 6. Логировать в историю                │
└─────────────────────────────────────────┘
```

### 4️⃣ Импорт заказов из CRM

#### Алгоритм дедупликации:
```
Входящий заказ:
┌──────────────────────────────────────────┐
│ {                                        │
│   email: "client@example.com",          │
│   products: ["Product A", "Product B"], │
│   date: "2024-01-15",                   │
│   total: 1500                           │
│ }                                        │
└──────────────────────────────────────────┘

Проверка дубликатов:
1. Создать hash:
   hash = MD5(email + products + date + total)

2. Проверить в таблице order_hashes:
   IF hash EXISTS:
     ⛔ Заказ уже импортирован
     LOG: duplicate_from_{source}
     SKIP
   ELSE:
     ✅ Новый заказ
     INSERT order_hash
     PROCEED

3. Объединение клиента:
   IF customer EXISTS (by email):
     UPDATE total_orders, total_spent
     ADD to purchase_history
   ELSE:
     CREATE new customer
     ADD to purchase_history
```

#### Импорт из внешней CRM:
```
Поддерживаемые форматы:
- CSV/Excel файл
- API интеграция (webhook)
- Прямое подключение к БД CRM

Маппинг полей:
email → email (required)
name → first_name + last_name
phone → phone
products → JSON array
date → order_date
amount → total
```

### 5️⃣ База знаний и индексация

#### Что хранится:
```
Customers:
- Демография (имя, пол, ДР)
- История покупок
- Предпочтения
- История рассылок
- Engagement метрики

Purchase History:
- Все заказы
- Товары и категории
- Суммы и даты
- Источник (сайт/CRM)

Campaigns:
- Отправленные офферы
- Персонализация данные
- Статистика (open/click/convert)
- A/B тесты результаты
```

#### Автоматическая очистка старых данных:
```
Cron еженедельно:
┌─────────────────────────────────────────┐
│ Retention policy (настраиваемо):        │
│ - Purchase history: 365 дней            │
│ - Campaign logs: 180 дней               │
│ - Email queue (sent): 30 дней           │
│ - Analytics temp: 90 дней               │
└─────────────────────────────────────────┘

Алгоритм:
1. Архивировать в JSON (опционально)
2. Удалить из основных таблиц
3. Обновить summary statistics
4. Логировать cleanup report
```

### 6️⃣ Генерация баннеров с AI

#### Для каждого персонализированного оффера:
```
Запрос к AI:
┌────────────────────────────────────────┐
│ "Создай концепцию баннера для:        │
│ - Клиент: {name}, {gender}, {age}    │
│ - Товары: {product_list}             │
│ - Скидка: {discount}%                │
│ - Стиль: {brand_style}               │
│                                        │
│ Вернуть:                               │
│ - Prompt для DALL-E/Midjourney        │
│ - Текст на баннере                    │
│ - Цветовая схема                      │
│ - Композиция                          │
│ "                                      │
└────────────────────────────────────────┘

Интеграция:
- DALL-E 3 (OpenAI)
- Stable Diffusion
- Midjourney API
- Canva API (шаблоны)

Сохранение:
- Генерация → Upload to media library
- URL → personalized_offers.banner_url
- Добавление в email template
```

### 7️⃣ Отслеживание эффективности

#### Метрики для каждого оффера:
```
Campaign level:
- Sent: общее количество
- Delivered: % доставки
- Opened: % открытий
- Clicked: % кликов
- Converted: % конверсии
- Revenue: доход от кампании

Personal level (per customer):
- Engagement score
- Best time to send
- Preferred products
- Response rate history
```

#### AI анализ результатов:
```
После каждой кампании:
1. Собрать все метрики
2. Отправить в AI для анализа
3. Получить insights:
   - Что сработало лучше?
   - Какие сегменты конвертят?
   - Оптимальное время отправки
   - Recommendations для следующей кампании
```
