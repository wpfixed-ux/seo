# AI Marketing Assistant для WordPress

Мощный плагин для автоматизации маркетинга с использованием искусственного интеллекта Claude AI. Анализирует покупки, сегментирует аудиторию, генерирует персонализированные офферы и автоматизирует email и Telegram рассылки.

## 🚀 Основные возможности

### 📊 Анализ клиентов
- Автоматический анализ покупок клиентов
- Определение паттернов покупательского поведения
- Расчет Lifetime Value (LTV)
- Определение рисков оттока клиентов
- Объединение дубликатов клиентов

### 👥 Сегментация аудитории
- Автоматическое создание сегментов на основе:
  - Суммы покупок
  - Количества заказов
  - Даты последней покупки
  - Категорий товаров
  - Истории взаимодействий
- Готовые шаблоны сегментов:
  - VIP клиенты
  - Активные покупатели
  - Группа риска (неактивные)
  - Разовые покупатели
  - Частые покупатели
- Конструктор пользовательских сегментов

### 🤖 AI-генерация офферов
- Автоматическая генерация персонализированных предложений через Claude AI
- Создание:
  - Заголовков и подзаголовков
  - Текста писем
  - Call-to-Action кнопок
  - Купонов со скидками
  - Концепций баннеров
- Учет истории покупок клиента
- Адаптация под сегменты аудитории

### 📧 Email-кампании
- Массовая рассылка персонализированных писем
- HTML-шаблоны с адаптивным дизайном
- Автоматическое создание WooCommerce купонов
- Отслеживание:
  - Доставки
  - Открытий
  - Кликов
  - Конверсий
- Планировщик автоматических рассылок

### 📱 Telegram-бот
- Автоматическая рассылка офферов в Telegram
- Подписка клиентов через бота
- Интеграция с thank you page WooCommerce
- Персонализированные сообщения
- Inline-кнопки с ссылками на товары

### 📥 Импорт базы клиентов
- Загрузка CSV/Excel файлов
- Автоматическое распознавание колонок
- Объединение с существующими клиентами
- Создание истории покупок из импорта
- Поддержка импорта из других магазинов сети

### 🛒 Интеграция с WooCommerce
- Автоматическое отслеживание заказов
- Синхронизация базы клиентов
- Рекомендации товаров на основе истории
- Виджет персональных рекомендаций
- Отображение предложения подписки на Telegram

## 📋 Требования

- WordPress 6.0 или выше
- PHP 8.0 или выше
- WooCommerce 6.0+ (опционально, но рекомендуется)
- Claude AI API ключ (получить на anthropic.com)
- Telegram Bot Token (опционально, для Telegram рассылок)

## 🔧 Установка

1. Скопируйте папку `ai-marketing-assistant` в директорию `/wp-content/plugins/`
2. Активируйте плагин в админ-панели WordPress
3. Перейдите в **AI Marketing → Settings** для настройки

## ⚙️ Настройка

### Claude AI API
1. Зарегистрируйтесь на [anthropic.com](https://anthropic.com)
2. Получите API ключ
3. Вставьте ключ в настройки плагина: **AI Marketing → Settings**
4. Выберите модель (рекомендуется: `claude-3-5-sonnet-20241022`)

### Telegram Bot (опционально)
1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите Bot Token
3. Вставьте токен в настройки плагина
4. Настройте webhook (автоматически при сохранении настроек)

### Email настройки
- Настройте имя отправителя
- Укажите email отправителя
- Настройте частоту рассылок

## 📖 Использование

### 1. Импорт базы клиентов

**Формат CSV файла:**
```csv
email,first_name,last_name,phone,products,order_date,amount
client@example.com,Иван,Петров,+380501234567,Товар 1,2024-01-15,1500
```

**Шаги:**
1. Перейдите в **AI Marketing → Import**
2. Выберите CSV файл
3. Нажмите "Upload and Import"
4. Дождитесь завершения импорта

### 2. Создание сегментов

**Готовые шаблоны:**
- Используйте кнопку "Create from Template"
- Выберите готовый сегмент
- Нажмите "Update Segment" для пересчета

**Пользовательский сегмент:**
1. **AI Marketing → Segments → Create New**
2. Задайте название и описание
3. Добавьте условия через конструктор:
   - Поле (Total Spent, Total Orders, Last Order Date, и т.д.)
   - Оператор (>, <, =, >=, <=)
   - Значение
4. Сохраните сегмент

**Примеры условий:**
- `Total Spent > 50000` - клиенты потратившие больше 50000₽
- `Total Orders >= 5` - частые покупатели (5+ заказов)
- `Last Order Date < -60 days` - неактивные 60+ дней

### 3. Создание оффера с AI

1. **AI Marketing → Offers → Create New**
2. Выберите целевой сегмент
3. Выберите товары для продвижения (опционально)
4. Нажмите **"Generate with AI"**
5. AI автоматически создаст:
   - Персонализированный текст
   - Заголовок и подзаголовок
   - Купон со скидкой
   - Call-to-Action
6. Отредактируйте при необходимости
7. Сохраните оффер

### 4. Запуск кампании

**Email рассылка:**
1. Откройте сохраненный оффер
2. Проверьте предпросмотр
3. Нажмите **"Send Email Campaign"**
4. Подтвердите отправку

**Telegram рассылка:**
1. Откройте оффер
2. Нажмите **"Send Telegram Campaign"**
3. Сообщения будут отправлены подписчикам из сегмента

**Планирование:**
- Установите дату и время в поле "Scheduled At"
- Кампания отправится автоматически

### 5. Аналитика

**Dashboard:**
- Общая статистика (клиенты, заказы, выручка)
- Топ товары
- Активные сегменты

**Analytics:**
- Детальная аналитика за период
- LTV по сегментам
- Retention rate
- Графики и диаграммы

**Статистика кампаний:**
- Количество отправленных
- Open rate (процент открытий)
- Click rate (процент кликов)
- Conversion rate (процент конверсий)

## 🗂️ Структура базы данных

Плагин создает следующие таблицы:

- `wp_aima_customers` - клиенты
- `wp_aima_purchase_history` - история покупок
- `wp_aima_segments` - сегменты
- `wp_aima_segment_members` - члены сегментов
- `wp_aima_offers` - офферы и кампании
- `wp_aima_campaign_recipients` - получатели кампаний
- `wp_aima_telegram_subscribers` - подписчики Telegram
- `wp_aima_import_logs` - логи импорта

## 🔄 Автоматизация

Плагин использует WP Cron для автоматических задач:

- **Ежедневно:** Обновление аналитики клиентов
- **Каждый час:** Проверка и отправка запланированных кампаний
- **Дважды в день:** Обновление сегментов

## 🎯 Примеры использования

### Пример 1: Реактивация неактивных клиентов

1. Создайте сегмент:
   - `Last Order Date < -60 days`
   - `Total Orders > 1`
2. Сгенерируйте оффер типа "Reactivation"
3. Добавьте купон на 20%
4. Отправьте email кампанию

### Пример 2: Кросс-продажи для VIP клиентов

1. Создайте сегмент:
   - `Total Spent > 100000`
2. Выберите дополнительные товары
3. Сгенерируйте оффер типа "Cross-sell"
4. Отправьте через Telegram для мгновенной реакции

### Пример 3: Приветствие новых клиентов

1. Создайте сегмент:
   - `Created At > -7 days`
   - `Total Orders = 1`
2. Сгенерируйте welcome оффер
3. Настройте автоматическую еженедельную отправку

## 🛠️ API и расширения

### Хуки (Hooks)

```php
// Перед отправкой email
do_action('aima_before_send_email', $recipient, $offer);

// После отправки email
do_action('aima_after_send_email', $recipient, $offer, $result);

// При обновлении сегмента
do_action('aima_segment_updated', $segment_id, $customer_count);

// При импорте клиента
do_action('aima_customer_imported', $customer_id, $source_data);
```

### Фильтры (Filters)

```php
// Изменить контент email
apply_filters('aima_email_content', $content, $offer, $customer);

// Изменить условия сегментации
apply_filters('aima_segment_conditions', $conditions, $segment_id);

// Изменить AI промпт
apply_filters('aima_ai_prompt', $prompt, $context);
```

## 🔒 Безопасность

- Все AJAX запросы защищены nonce
- SQL запросы используют prepared statements
- Данные санитизируются перед сохранением
- API ключи хранятся в зашифрованном виде
- Проверка прав доступа для всех операций
