# WooCommerce AI Sales Assistant

AI-ассистент для WooCommerce с локальной векторной базой данных для интеллектуальных рекомендаций товаров.

## Возможности

- **Векторная база данных** - локальное хранение эмбеддингов для быстрого семантического поиска
- **Индексация контента** - автоматическое изучение товаров и статей с созданием базы знаний
- **Умный поиск** - семантический поиск по товарам с учётом контекста
- **AI-консультант** - чат-бот для помощи в выборе товаров с информацией о ценах и наличии
- **Мультиязычность** - поддержка русского и украинского языков
- **Несколько AI-провайдеров** - OpenAI, Claude, Kimi на выбор

## Установка

1. Загрузите папку `woo-ai-assistant` в `/wp-content/plugins/`
2. Активируйте плагин в меню "Плагины"
3. Перейдите в "AI Ассистент" → "Настройки"
4. Введите API ключи для выбранного провайдера
5. Нажмите "Начать индексацию" для создания базы знаний

## Шорткоды

### Строка поиска
```
[waa_search placeholder="Найти товар..." language="ru"]
```

### Встроенный чат
```
[waa_chat title="AI Консультант" language="ru" height="400"]
```

### Плавающая кнопка
```
[waa_floating position="bottom-right" language="ru"]
```

## Настройки

### API провайдеры

- **OpenAI** - GPT-4, GPT-3.5, эмбеддинги text-embedding-3
- **Claude** - Claude 3.5 Sonnet (требует OpenAI для эмбеддингов)
- **Kimi** - Moonshot AI (требует OpenAI для эмбеддингов)

### Языки

- Русский (ru)
- Українська (uk)

Ассистент автоматически определяет язык запроса пользователя.

### Индексация

При индексации собирается информация о:
- Название товара
- Цена (обычная, со скидкой)
- Наличие на складе
- Категории и теги
- Описание и характеристики
- URL страницы товара

## REST API

### POST /wp-json/waa/v1/chat
Отправка сообщения в чат.

```json
{
  "message": "Ищу ноутбук для работы",
  "session_id": "uuid",
  "language": "auto"
}
```

### POST /wp-json/waa/v1/search
Семантический поиск товаров.

```json
{
  "query": "ноутбук для игр",
  "limit": 5,
  "language": "ru"
}
```

### GET /wp-json/waa/v1/welcome
Получение приветственного сообщения.

## Требования

- WordPress 5.8+
- WooCommerce 5.0+
- PHP 7.4+
- API ключ OpenAI (обязателен для эмбеддингов)
