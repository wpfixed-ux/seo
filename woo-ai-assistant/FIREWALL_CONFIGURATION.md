# Настройка сетевого экрана (Firewall) для Woo AI Assistant

## Проблема

При включенном сетевом экране (firewall) плагин не работает и показывает ошибку: **"Произошла ошибка. Попробуйте снова."**

Это происходит потому, что firewall блокирует исходящие HTTPS запросы к внешним API сервисам.

## Решение

Необходимо добавить следующие домены в **белый список (исключения)** вашего сетевого экрана:

### Обязательные домены (в зависимости от выбранного AI провайдера)

#### 1. Если используется OpenAI (по умолчанию):
```
api.openai.com
```

**Используется для:**
- Чат с AI консультантом
- Генерация векторных представлений для поиска (embeddings)
- Распознавание голоса (Whisper API)

**Endpoints:**
- `https://api.openai.com/v1/chat/completions`
- `https://api.openai.com/v1/embeddings`
- `https://api.openai.com/v1/audio/transcriptions`
- `https://api.openai.com/v1/models`

#### 2. Если используется Claude (Anthropic):
```
api.anthropic.com
api.openai.com
```

**Используется для:**
- Чат с AI консультантом (Claude)
- Генерация embeddings (OpenAI, т.к. Claude не имеет своих embeddings)

**Endpoints:**
- `https://api.anthropic.com/v1/messages`
- `https://api.openai.com/v1/embeddings`

#### 3. Если используется Kimi (Moonshot):
```
api.moonshot.cn
api.openai.com
```

**Используется для:**
- Чат с AI консультантом (Kimi)
- Генерация embeddings (OpenAI, т.к. Kimi не имеет своих embeddings)

**Endpoints:**
- `https://api.moonshot.cn/v1/chat/completions`
- `https://api.moonshot.cn/v1/models`
- `https://api.openai.com/v1/embeddings`

## Инструкции по настройке различных Firewall

### Windows Defender Firewall

1. Откройте **Панель управления** → **Система и безопасность** → **Брандмауэр Защитника Windows**
2. Нажмите **Дополнительные параметры**
3. Выберите **Правила для исходящих подключений**
4. Нажмите **Создать правило**
5. Выберите тип правила: **Настраиваемое**
6. В разделе **Протокол и порты** выберите:
   - Протокол: **TCP**
   - Удаленный порт: **443** (HTTPS)
7. В разделе **Область** добавьте удаленные IP-адреса или оставьте "Любой IP-адрес"
8. Выберите действие: **Разрешить подключение**
9. Выберите профили: **Доменный, Частный, Публичный**
10. Задайте имя правила: "Woo AI Assistant - OpenAI API"

**Примечание:** Windows Firewall не поддерживает фильтрацию по доменным именам напрямую. Для более точного контроля используйте сторонние firewall решения.

### Kaspersky Internet Security

1. Откройте **Kaspersky Internet Security**
2. Перейдите в **Настройки** → **Дополнительно** → **Сеть**
3. Нажмите **Выбрать доверенные адреса**
4. Добавьте домены:
   - `api.openai.com`
   - `api.anthropic.com` (если используется Claude)
   - `api.moonshot.cn` (если используется Kimi)
5. Нажмите **OK** и **Сохранить**

### ESET NOD32 / Internet Security

1. Откройте **ESET**
2. Нажмите **F5** для открытия расширенных настроек
3. Перейдите в **Интернет и электронная почта** → **Веб-доступ и электронная почта** → **Управление URL-адресами**
4. Нажмите **Изменить** рядом со списком адресов
5. Нажмите **Добавить** и введите:
   - `https://api.openai.com/*`
   - `https://api.anthropic.com/*` (если используется Claude)
   - `https://api.moonshot.cn/*` (если используется Kimi)
6. Выберите **Разрешить** для каждого адреса
7. Нажмите **OK** и сохраните настройки

### Dr.Web Security Space

1. Откройте **Dr.Web Security Space**
2. Перейдите в **SpIDer Gate** (компонент веб-антивируса)
3. Откройте **Настройки** → **Исключения**
4. Добавьте URL-адреса в белый список:
   - `https://api.openai.com/*`
   - `https://api.anthropic.com/*` (если используется Claude)
   - `https://api.moonshot.cn/*` (если используется Kimi)
5. Сохраните изменения

### Avast / AVG Internet Security

1. Откройте **Avast** или **AVG**
2. Перейдите в **Меню** → **Настройки**
3. Выберите **Основные компоненты** → **Веб-экран**
4. Нажмите **Настройка** → **Исключения**
5. Добавьте URL-адреса:
   - `https://api.openai.com/*`
   - `https://api.anthropic.com/*` (если используется Claude)
   - `https://api.moonshot.cn/*` (если используется Kimi)
6. Нажмите **OK**

### Bitdefender

1. Откройте **Bitdefender**
2. Перейдите в **Защита** → **Просмотр функций**
3. Откройте настройки **Веб-защита**
4. Перейдите в **Исключения**
5. Добавьте домены:
   - `api.openai.com`
   - `api.anthropic.com` (если используется Claude)
   - `api.moonshot.cn` (если используется Kimi)
6. Сохраните изменения

### Корпоративные Firewall (pfSense, Cisco ASA, FortiGate и др.)

Для корпоративных firewall создайте правило исходящего трафика:

**Параметры правила:**
- **Протокол:** TCP
- **Порт назначения:** 443 (HTTPS)
- **Назначение:**
  - `api.openai.com`
  - `api.anthropic.com` (если используется Claude)
  - `api.moonshot.cn` (если используется Kimi)
- **Действие:** Разрешить (Allow)

## Проверка подключения

После настройки firewall проверьте подключение:

1. Откройте админ-панель WordPress
2. Перейдите в **Woo AI Assistant** → **Настройки**
3. Нажмите кнопку **"Проверить подключение"**
4. Если настройка выполнена правильно, вы увидите сообщение: **"Connection successful!"**

## Устранение неполадок

### Если ошибка все еще появляется:

1. **Очистите кэш браузера и WordPress**
   - Нажмите Ctrl+Shift+Del в браузере
   - Очистите кэш WordPress (если используется кэширующий плагин)

2. **Проверьте логи ошибок**
   - Откройте **Woo AI Assistant** → **Логи API**
   - Найдите последние ошибки и их описание

3. **Проверьте, что API ключ настроен правильно**
   - Перейдите в **Woo AI Assistant** → **Настройки**
   - Убедитесь, что API ключ введен правильно
   - Используйте кнопку "Проверить подключение"

4. **Временно отключите firewall для теста**
   - Отключите firewall на 1-2 минуты
   - Попробуйте отправить сообщение в чат
   - Если работает - проблема в настройках firewall
   - Включите firewall обратно и проверьте настройки

5. **Проверьте порт 443**
   - Убедитесь, что исходящий трафик на порт 443 (HTTPS) не заблокирован

6. **Проверьте прокси-сервер**
   - Если используется прокси, убедитесь, что он не блокирует эти домены

## Требования к сети

- **Протокол:** HTTPS (TLS 1.2 или выше)
- **Порт:** 443
- **Метод:** POST, GET
- **Тип контента:** application/json, multipart/form-data (для аудио)
- **Таймаут:** Минимум 30 секунд (рекомендуется 60 секунд)

## Дополнительная информация

### Зачем нужны эти подключения?

- **OpenAI API** - предоставляет модели GPT для общения с клиентами, создание векторных представлений для семантического поиска, распознавание речи
- **Claude API** - альтернативный AI провайдер от Anthropic
- **Kimi API** - китайский AI провайдер от Moonshot

### Безопасность

Все подключения:
- Используют шифрование HTTPS (TLS)
- Требуют API ключи для аутентификации
- Не передают конфиденциальную информацию клиентов
- Соответствуют стандартам безопасности API провайдеров

### Приватность данных

Плагин отправляет только:
- Текст сообщений пользователей
- Информацию о товарах из вашего магазина (название, описание, цена)
- Аудио для распознавания речи (только если используется голосовой ввод)

**Не отправляются:**
- Персональные данные пользователей
- Платежная информация
- Пароли и логины
- IP-адреса клиентов

## Поддержка

Если у вас остались вопросы или проблемы с настройкой firewall, пожалуйста:

1. Проверьте логи ошибок в админ-панели плагина
2. Убедитесь, что используется правильный AI провайдер
3. Проверьте, что все необходимые домены добавлены в исключения
4. Свяжитесь с администратором сети, если используется корпоративный firewall
