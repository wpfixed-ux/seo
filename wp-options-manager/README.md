# WP Options Table Manager

WordPress плагин для диагностики, мониторинга и безопасной очистки таблицы `wp_options`.

## Описание

WP Options Table Manager - это мощный инструмент для оптимизации производительности WordPress сайтов путем анализа и очистки таблицы `wp_options`. Плагин помогает предотвратить засорение базы данных некачественными плагинами и оптимизировать загрузку сайта.

## Возможности

### Фаза 1 (MVP) - Реализовано

#### 1. Диагностика таблицы wp_options

- **Общая статистика:**
  - Текущий размер таблицы в MB
  - Количество записей
  - Размер autoload данных (с индикаторами: зеленый < 500KB, желтый < 800KB, красный > 800KB)
  - Количество autoload записей
  - Сравнение с рекомендуемыми значениями

- **Анализ по типам данных:**
  - Группировка записей по префиксам (transients, WooCommerce, widgets, и т.д.)
  - Размер каждой группы в KB/MB
  - Количество записей в группе

- **Топ проблемных записей:**
  - Список 20 самых больших записей
  - Размер в KB/MB
  - Статус autoload
  - Источник (определение плагина, который создал опцию)

#### 2. Безопасная очистка

- **Transients:**
  - Очистка истекших transients
  - Очистка orphaned transients (без таймаутов)

- **WooCommerce сессии:**
  - Очистка истекших сессий (с сохранением активных корзин)
  - Опция принудительной очистки всех сессий (с предупреждением)

- **Очистка по паттерну:**
  - Предпросмотр удаляемых данных
  - Подсчет количества и размера
  - Защита критических WordPress опций

- **Оптимизация autoload:**
  - Автоматическое отключение autoload для больших опций (> 100KB)

#### 3. Безопасность

- **Резервное копирование:**
  - Автоматическое создание бэкапа перед удалением
  - Хранение удаленных данных в течение 7 дней

- **Защита критических опций:**
  - Список защищенных WordPress опций
  - Проверка перед удалением

- **SQL безопасность:**
  - Prepared statements для всех запросов
  - Транзакции для критических операций
  - OPTIMIZE TABLE после удаления

#### 4. Интерфейс администратора

- **Dashboard:**
  - Виджет состояния таблицы
  - Быстрые действия для частых операций
  - Цветовые индикаторы состояния

- **Diagnostic:**
  - Детальная информация по типам данных
  - Таблица топ-20 больших опций
  - Кэширование результатов (1 час)

- **Cleaner:**
  - Интерфейс для различных типов очистки
  - AJAX операции без перезагрузки
  - Прогресс-индикаторы
  - Уведомления о результатах

#### 5. База данных

Плагин создает собственные таблицы:

- `{prefix}_wpo_logs` - логи всех операций
- `{prefix}_wpo_history` - история изменений таблицы wp_options
- `{prefix}_wpo_backup` - резервные копии удаленных записей

## Системные требования

- WordPress 5.0+
- PHP 7.4+
- MySQL 5.6+
- WooCommerce 5.0+ (опционально, для работы с сессиями WC)

## Установка

1. Загрузите папку `wp-options-manager` в директорию `/wp-content/plugins/`
2. Активируйте плагин через меню 'Plugins' в WordPress
3. Перейдите в меню 'Options Manager' для начала работы

## Использование

### Dashboard

1. Откройте меню **Options Manager → Dashboard**
2. Просмотрите общую статистику таблицы
3. Используйте быстрые действия для очистки данных
4. Обратите внимание на цветовые индикаторы состояния autoload

### Diagnostic

1. Откройте меню **Options Manager → Diagnostic**
2. Изучите данные по типам (префиксам)
3. Проверьте топ-20 больших опций
4. Определите источники проблем

### Cleaner

1. Откройте меню **Options Manager → Cleaner**
2. Выберите тип очистки:
   - **Transients** - очистка кэша
   - **WooCommerce Sessions** - очистка сессий
   - **By Pattern** - очистка по паттерну
   - **Autoload Optimization** - оптимизация autoload

3. Просмотрите предварительную информацию
4. Подтвердите операцию

## Безопасность

### Защищенные опции

Плагин никогда не удалит следующие критические WordPress опции:

- `siteurl`, `home`, `blogname`
- `admin_email`
- `active_plugins`
- `template`, `stylesheet`
- `permalink_structure`, `rewrite_rules`
- И другие критические настройки WordPress

### Резервное копирование

Все удаленные записи сохраняются в таблице `wp_wpo_backup` в течение 7 дней и могут быть восстановлены при необходимости.

## Производительность

- **Кэширование:** Результаты диагностики кэшируются на 1 час
- **Batch Processing:** Обработка больших объемов данных порциями
- **AJAX операции:** Асинхронные операции не блокируют интерфейс
- **Оптимизация:** Автоматический OPTIMIZE TABLE после удаления

## Рекомендации

1. **Регулярная очистка:** Запускайте очистку transients еженедельно
2. **Мониторинг autoload:** Следите, чтобы размер autoload был < 800 KB
3. **Резервные копии:** Делайте резервные копии БД перед массовыми операциями
4. **Тестирование:** Проверяйте работу сайта после очистки
