# AI Image Generator для WordPress

WordPress плагин для автоматической генерации изображений для статей и замены фона товаров с использованием Gemini AI.

## Описание

AI Image Generator - это мощный плагин, который использует искусственный интеллект для:

1. **Генерации изображений для статей** - анализирует содержание статьи через Gemini AI и генерирует подходящее изображение
2. **Замены фона товаров** - удаляет фон с изображений товаров и применяет новые фоны (белый, градиентный, 3D, AI-генерированный)
3. **Применения водяных знаков** - настраиваемый водяной знак для всех сгенерированных изображений

## Возможности

### Для статей и страниц:
- Автоматический анализ содержания статьи через Gemini AI
- Генерация промпта для создания изображения
- Создание изображения через Stability AI (Stable Diffusion) или OpenAI (DALL-E 3)
- Автоматическая установка как Featured Image
- Метабокс в редакторе для быстрой генерации

### Для товаров WooCommerce:
- Удаление фона с изображений товаров
- Замена фона на:
  - Белый
  - Градиентный (настраиваемые цвета)
  - 3D студийный (имитация освещения)
  - AI-генерированный (на основе описания товара)
- Метабокс в редакторе товаров

### Водяные знаки:
- Текстовый или графический водяной знак
- Настраиваемая позиция (5 вариантов)
- Регулируемая прозрачность
- Единые настройки для всех изображений

## Системные требования

- WordPress 5.0+
- PHP 7.4+
- WooCommerce 5.0+ (опционально, для функций товаров)

## API Ключи

Для работы плагина требуются API ключи:

### Обязательные:
1. **Gemini API** (Google AI) - для анализа контента
   - Получить: https://makersuite.google.com/app/apikey
   - Используется для создания промптов

2. **Image Generation API** - для генерации изображений
   - **Stability AI**: https://platform.stability.ai/account/keys
   - **OpenAI DALL-E**: https://platform.openai.com/api-keys

### Опциональные (для товаров):
3. **Background Removal API** - для удаления фона
   - **Remove.bg**: https://www.remove.bg/api
   - **ClipDrop**: https://clipdrop.co/apis

## Установка

1. Загрузите папку `ai-image-generator` в `/wp-content/plugins/`
2. Активируйте плагин через меню 'Plugins' в WordPress
3. Перейдите в меню **AI Images → Настройки**
4. Введите необходимые API ключи
5. Настройте водяной знак (опционально)

## Использование

### Генерация изображений для статей:

1. Создайте или откройте статью/страницу
2. В правом сайдбаре найдите метабокс **"AI Image Generator"**
3. Нажмите кнопку **"Сгенерировать изображение"**
4. Плагин проанализирует содержание и создаст изображение
5. Изображение автоматически установится как Featured Image

### Замена фона товаров:

1. Откройте товар WooCommerce
2. Убедитесь, что у товара есть Featured Image
3. В правом сайдбаре найдите метабокс **"AI Background Replace"**
4. Выберите тип фона из выпадающего списка
5. Нажмите кнопку **"Заменить фон"**
6. Плагин создаст новое изображение с выбранным фоном

## Настройки

### API Ключи
- **Gemini API Key** - ключ для Google Gemini AI
- **Gemini Model** - выбор модели (gemini-pro рекомендуется)
- **Image API Provider** - провайдер для генерации (Stability AI или OpenAI)
- **Image API Key** - ключ выбранного провайдера
- **Background Removal Provider** - Remove.bg или ClipDrop
- **Background Removal API Key** - ключ для удаления фона

### Водяной знак
- **Включить водяной знак** - применять ко всем изображениям
- **Текст водяного знака** - текст для наложения
- **Позиция** - расположение водяного знака
- **Прозрачность** - от 0 до 100%

## Типы фона для товаров

1. **Белый фон** - чистый белый (#FFFFFF)
2. **Градиентный фон** - градиент из двух цветов
3. **3D студийный фон** - имитация студийного освещения
4. **AI-генерированный фон** - уникальный фон на основе описания товара

## Рабочий процесс

### Для статьи:
```
Содержание статьи → Gemini AI (анализ) → Промпт → Image AI (генерация) → Водяной знак → Featured Image
```

### Для товара:
```
Изображение товара → Remove Background → Новый фон → Водяной знак → Новое изображение
```

## Метаданные

Плагин сохраняет следующие метаданные:

- `_aimg_generated` - флаг сгенерированного изображения
- `_aimg_prompt` - использованный промпт
- `_aimg_generated_date` - дата генерации
- `_aimg_original_id` - ID оригинального изображения (для товаров)
- `_aimg_background_type` - тип примененного фона

## Ограничения

- Генерация изображения может занять до 60 секунд
- Зависит от лимитов API провайдеров
- Размер изображений ограничен настройками провайдера
- Качество зависит от выбранной модели и промпта

## Безопасность

- Все API ключи хранятся в базе данных WordPress
- Nonce проверки для всех AJAX запросов
- Capability checks (edit_posts, manage_options)
- Sanitization всех пользовательских вводов

## Кэширование

Плагин создает временную папку для кэша:
- Путь: `/wp-content/uploads/ai-image-generator-cache/`
- Используется для временного хранения изображений
- Защищена .htaccess
