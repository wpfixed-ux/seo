# Инструкция по установке AI SEO Interlinking

## Быстрая установка

### 1. Загрузка плагина

Скопируйте папку `ai-seo-interlinking` в директорию плагинов WordPress:

```bash
cp -r ai-seo-interlinking /path/to/wordpress/wp-content/plugins/
```

Или создайте ZIP архив и установите через админ панель:

```bash
cd ai-seo-interlinking
zip -r ../ai-seo-interlinking.zip .
```

### 2. Активация

1. Войдите в админ панель WordPress
2. Перейдите в **Плагины → Установленные**
3. Найдите **AI SEO Interlinking**
4. Нажмите **Активировать**

### 3. Настройка OpenAI API

1. Получите API ключ на [OpenAI Platform](https://platform.openai.com/api-keys)
2. В WordPress перейдите в **AI Interlinking → Settings**
3. На вкладке **API Settings**:
   - Вставьте API ключ
   - Выберите модель (рекомендуется GPT-3.5 Turbo)
   - Нажмите **Test Connection**

### 4. Настройка стратегии

1. Перейдите на вкладку **Linking Strategy**
2. Выберите стратегию перелинковки:
   - **Pyramid** - для интернет-магазинов
   - **Cluster** - для тематических сайтов
   - **AI Auto** - автоматический выбор
3. Настройте параметры:
   - Max Outbound Links: 5
   - Max Inbound Links: 10
   - Min Content Length: 300 слов
4. Сохраните настройки

### 5. Первый запуск

**Вариант A: Ручная обработка**
1. Перейдите на вкладку **Scheduler**
2. Нажмите **Process Batch Now**
3. Дождитесь завершения обработки

**Вариант B: Автоматическая обработка**
1. На вкладке **Scheduler** включите **Enable Scheduler**
2. Выберите частоту: Daily
3. Установите время: 02:00 (ночью)
4. Batch Size: 50
5. Сохраните настройки

### 6. Проверка результатов

1. Перейдите в **AI Interlinking → Reports**
2. Просмотрите статистику:
   - Количество созданных ссылок
   - Использование API
   - Топ страниц
3. Проверьте логи в **AI Interlinking → Logs**

## Требования

✅ WordPress 5.8+
✅ PHP 7.4+
✅ WooCommerce 6.0+
✅ OpenAI API ключ
⚠️ (Опционально) Polylang или WPML для мультиязычности

## Устранение проблем

### Ошибка "WooCommerce required"
Установите и активируйте WooCommerce.

### Ошибка "Invalid API key"
Проверьте правильность API ключа на странице настроек.

### Ссылки не создаются
1. Проверьте минимальную длину контента (300 слов по умолчанию)
2. Убедитесь, что страницы не исключены
3. Проверьте логи для выявления ошибок

## Дополнительная настройка

### Мультиязычность

Если используете Polylang или WPML:
1. Плагин автоматически определит установленный плагин
2. Ссылки будут создаваться отдельно для каждого языка
3. Настройте ключевые слова для каждого языка отдельно

### Исключение страниц

Чтобы исключить определенные страницы:
1. Перейдите в **Settings → Linking Strategy**
2. В поле **Excluded Pages** выберите нужные страницы
3. Сохраните настройки

### Настройка AI промпта

Для кастомизации генерации ключевых слов:
1. Перейдите на вкладку **Keywords**
2. Измените **AI Prompt Template**
3. Используйте переменные: `{post_title}`, `{post_content}`, `{category}`, `{language}`
4. Сохраните изменения
