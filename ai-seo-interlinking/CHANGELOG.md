## Как обновить

### Для существующих пользователей:

1. **Обновите плагин через Git:**
   ```bash
   cd wp-content/plugins/ai-seo-interlinking
   git pull origin claude/ai-seo-interlinking-012KLieDues2yCBGpMdstpxS
   ```

2. **Проверьте API ключ:**
   - Откройте: AI Interlinking → Settings → API Settings
   - Если видите зеленую галочку ✅ - ключ сохранен
   - Если нет - введите ключ заново и нажмите Save

3. **Обновите модель (рекомендуется):**
   - Модель: выберите **GPT-4o Mini**
   - Нажмите Save Changes
   - Проверьте Test Connection

4. **Готово!** Плагин автоматически начнет использовать новую модель

### Для новых пользователей:

Просто установите плагин - GPT-4o Mini уже установлена по умолчанию!
