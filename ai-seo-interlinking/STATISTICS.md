## 💰 Расчет стоимости

### Формулы расчета

Плагин автоматически считает стоимость по актуальным ценам OpenAI:

```php
GPT-3.5 Turbo: $0.0015 за 1K токенов
GPT-4:         $0.03 за 1K токенов
GPT-4 Turbo:   $0.01 за 1K токенов
```

**Формула:**
```
Стоимость = (Использовано токенов / 1000) × Цена модели
```

### Примеры расчета

**Пример 1: Генерация ключевых слов (GPT-3.5 Turbo)**
```
Токенов: 450
Стоимость: (450 / 1000) × $0.0015 = $0.000675 ≈ $0.0007
```

**Пример 2: Анализ релевантности (GPT-4)**
```
Токенов: 150
Стоимость: (150 / 1000) × $0.03 = $0.0045
```

**Пример 3: Пакетная обработка 100 постов (GPT-3.5 Turbo)**
```
Токенов: 35,000 (350 в среднем на пост)
Стоимость: (35,000 / 1000) × $0.0015 = $0.0525 ≈ $0.05
```

## 📈 Мониторинг расходов

### Дневной лимит

Для контроля расходов можно установить лимиты в настройках OpenAI:

1. Перейдите на [OpenAI Usage](https://platform.openai.com/usage)
2. Установите **Usage limits**
3. Получайте уведомления при превышении

### Оптимизация расходов

**Рекомендации:**

1. **Используйте GPT-3.5 Turbo** для массовых операций
   - В 20 раз дешевле GPT-4
   - Достаточно для генерации ключевых слов

2. **Настройте кеширование** (включено по умолчанию)
   - Результаты кешируются на 24 часа
   - Повторные запросы не тратят токены

3. **Оптимизируйте max_tokens**
   - Установите разумное значение (500)
   - Не используйте максимум (4000)

4. **Используйте планировщик**
   - Обрабатывайте по ночам
   - Контролируемые пакеты

5. **Мониторьте ошибки**
   - Ошибки тоже потребляют токены
   - Исправляйте проблемы вовремя

## 🔔 Уведомления

### Настройка алертов

Плагин показывает уведомления в виджете если:

- ❗ Стоимость за месяц > $5
- ❗ Есть необработанные ошибки
- ❗ Orphan pages > 20

### Email уведомления (в разработке)

Планируется добавить email уведомления при:
- Превышении бюджета
- Критических ошибках
- Завершении пакетной обработки

## ❓ FAQ

**Q: Как часто обновляется статистика?**
A: В реальном времени. Каждая операция сразу попадает в статистику.

**Q: Можно ли посмотреть статистику за другой период?**
A: Да, в logs можно фильтровать по датам. В следующей версии добавим выбор периода в Reports.

**Q: Стоимость точная или примерная?**
A: Примерная, основанная на актуальных ценах OpenAI на момент создания плагина. Точную стоимость смотрите в [OpenAI Usage](https://platform.openai.com/usage).

**Q: Где хранятся данные статистики?**
A: В таблицах WordPress БД: `wp_ai_interlinking_logs` и `wp_ai_interlinking_links`.

**Q: Можно ли очистить старые логи?**
A: Да, автоматически по расписанию (настраивается) или вручную на странице Logs.

**Q: Показывается ли статистика для каждого языка отдельно?**
A: Да, на странице Reports есть раздел "Statistics by Language".
