# Многоязычная поддержка AI SEO Interlinking

Плагин поддерживает работу с несколькими языками в трёх режимах:

## 🌍 Режимы работы

### 1. С Polylang
Если установлен Polylang, плагин автоматически использует его языки.

### 2. С WPML
Если установлен WPML, плагин автоматически использует его языки.

### 3. Standalone (без плагинов)
Можно вручную выбрать языки для обработки.

## ⚙️ Настройка языков (Standalone режим)

### Шаг 1: Откройте настройки
1. Перейдите в **AI Interlinking → Settings**
2. Откройте вкладку **Languages**

### Шаг 2: Выберите активные языки
Отметьте галочками языки, которые нужно обрабатывать:

```
☑ English (en)
☑ Русский (ru)
☑ Deutsch (de)
☐ Français (fr)
☐ Español (es)
...
```

### Шаг 3: Установите язык по умолчанию
Выберите основной язык сайта из выпадающего списка.

### Шаг 4: Выберите режим определения языка
- **Automatic** - использовать WordPress locale
- **Manual** - использовать выбранные языки

### Шаг 5: Сохраните настройки
Нажмите **Save Changes**.

## 🔄 Как работает обработка

### С Polylang/WPML
1. Плагин автоматически определяет язык каждой записи
2. Создаёт ссылки только между записями одного языка
3. Ведёт отдельную статистику для каждого языка

### В Standalone режиме
1. Плагин определяет язык по WordPress locale
2. Если язык не указан - использует язык по умолчанию
3. Обрабатывает только выбранные языки

## 📝 Переводы плагина

Плагин включает переводы интерфейса:

### Русский (ru_RU)
Файл: `languages/ai-seo-interlinking-ru_RU.po`
- Полный перевод всех пунктов меню
- Перевод сообщений и уведомлений
- Локализованные названия стратегий

### Немецкий (de_DE)
Файл: `languages/ai-seo-interlinking-de_DE.po`
- Полный перевод интерфейса
- Немецкая терминология

### Создание своих переводов

1. Скопируйте файл `ai-seo-interlinking.pot`
2. Переименуйте в `ai-seo-interlinking-{locale}.po` (например, `ai-seo-interlinking-fr_FR.po`)
3. Откройте в [Poedit](https://poedit.net/)
4. Переведите все строки
5. Сохраните (автоматически создастся .mo файл)
6. Поместите оба файла (.po и .mo) в папку `languages/`

## 🔧 Технические детали

### Определение языка записи

```php
// Для Polylang/WPML
$language = AIL_Multilang_Support::get_post_language($post_id);

// Для standalone режима
$settings = get_option('ail_settings');
$language = $settings['default_language'];
```


### Статистика по языку


## ❓ FAQ

**Q: Можно ли добавить свой язык?**
A: Да, отредактируйте метод `get_available_languages()` в `class-multilang.php`

**Q: Нужны ли .mo файлы?**
A: Да, скомпилируйте .po файлы в .mo используя Poedit

**Q: Работает ли без Polylang/WPML?**
A: Да, плагин работает в standalone режиме с ручным выбором языков

**Q: Можно ли создавать ссылки между языками?**
A: По умолчанию нет, но можно включить опцию `cross_language_linking` (в разработке)

**Q: Как AI понимает язык контента?**
A: Язык передаётся в AI промпт как переменная `{language}`
