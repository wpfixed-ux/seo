# AI SEO Interlinking Plugin для WordPress/WooCommerce

Автоматическая внутренняя перелинковка для мультиязычных сайтов WooCommerce с использованием искусственного интеллекта (OpenAI API).

## Описание

AI SEO Interlinking - это мощный WordPress плагин, который использует искусственный интеллект для автоматического создания оптимизированных внутренних ссылок на вашем сайте. Плагин анализирует контент, определяет релевантность страниц и создает естественные ссылки согласно лучшим практикам SEO.

## Основные возможности

### ✨ Интеллектуальная перелинковка
- **5 стратегий перелинковки**:
  - Силовая пирамида (Homepage → Categories → Products)
  - Кольцевая перелинковка (связывание страниц одного уровня)
  - Тематические кластеры (по семантической близости)
  - Хабовая модель (pillar pages + поддерживающий контент)
  - AI автоматический выбор оптимальной стратегии

### 🤖 Интеграция с OpenAI
- Поддержка моделей GPT-3.5 Turbo, GPT-4, GPT-4 Turbo
- Автоматическая генерация ключевых слов
- Анализ семантической релевантности контента
- Подбор естественных анкорных текстов

### 🌍 Мультиязычность
- **Три режима работы**: Polylang, WPML или Standalone (без плагинов)
- **14 языков**: английский, русский, немецкий, французский, испанский, итальянский, португальский, польский, голландский, турецкий, японский, китайский, корейский, арабский
- **Standalone режим**: ручной выбор языков для обработки без необходимости устанавливать Polylang/WPML
- Раздельная обработка и статистика для каждого языка
- Автоматическое определение языка из WordPress locale
- Переводы интерфейса плагина (русский, немецкий)
- Возможность добавления собственных языков и переводов

### 📊 Аналитика и отчеты
- **Dashboard виджет** на главной странице WordPress с мгновенной статистикой
- **Детальная страница отчетов** (AI Interlinking → Reports):
  - Всего ссылок создано (за всё время и за 30 дней)
  - API вызовов и использование токенов
  - **Автоматический расчет стоимости** в USD (GPT-3.5: ~$0.0015/1K, GPT-4: ~$0.03/1K)
  - Средняя стоимость за операцию
- **Топ-10 страниц** по входящим и исходящим ссылкам
- **Orphan pages** - список страниц без входящих ссылок
- **Статистика по языкам** - распределение ссылок и ключевых слов
- **Сводка операций** - детализация по типам операций
- **Полное логирование** всех операций с фильтрацией и поиском

## Установка

### Способ 1: Установка из ZIP архива

1. Скачайте плагин как ZIP архив
2. В админ панели WordPress перейдите в **Плагины → Добавить новый**
3. Нажмите **Загрузить плагин**
4. Выберите ZIP файл и нажмите **Установить**
5. Активируйте плагин

### Способ 2: Установка через FTP

1. Распакуйте ZIP архив
2. Загрузите папку `ai-seo-interlinking` в `/wp-content/plugins/`
3. В админ панели WordPress перейдите в **Плагины**
4. Найдите "AI SEO Interlinking" и нажмите **Активировать**

### Способ 3: Клонирование из GitHub

```bash
cd /path/to/wordpress/wp-content/plugins/
git clone https://github.com/your-repo/ai-seo-interlinking.git
```

## Быстрый старт

### 1. Получите OpenAI API ключ

1. Зарегистрируйтесь на [OpenAI Platform](https://platform.openai.com)
2. Перейдите в раздел [API Keys](https://platform.openai.com/api-keys)
3. Создайте новый API ключ
4. Скопируйте ключ (он начинается с `sk-`)

### 2. Настройте плагин

1. В WordPress перейдите в **AI Interlinking → Settings**
2. На вкладке **API Settings**:
   - Вставьте ваш OpenAI API ключ
   - Выберите модель (GPT-3.5 Turbo для экономии)
   - Нажмите **Test Connection**
3. На вкладке **Linking Strategy**:
   - Выберите стратегию перелинковки
   - Настройте максимальное количество ссылок
   - Установите минимальную длину контента
4. На вкладке **Languages** (если нет Polylang/WPML):
   - Выберите языки для обработки (английский, русский, немецкий и др.)
   - Установите язык по умолчанию
   - Выберите режим определения языка
5. Сохраните настройки

### 3. Запустите обработку

**Ручная обработка:**
- Перейдите на вкладку **Scheduler**
- Нажмите **Process Batch Now**

**Автоматическая обработка:**
- Включите **Enable Scheduler**
- Выберите частоту (ежедневно/еженедельно/ежемесячно)
- Установите время запуска
- Сохраните настройки

## Стратегии перелинковки

### 1. Силовая пирамида (Pyramid)

Иерархическая структура ссылок:
- Главная страница → Категории
- Категории → Товары
- Товары → Категории и главная

**Когда использовать:** Для интернет-магазинов с четкой структурой категорий.

### 2. Кольцевая (Circular)

Связывание страниц одного уровня между собой:
- Товары ↔ Товары
- Статьи ↔ Статьи

**Когда использовать:** Для блогов и контентных сайтов.

### 3. Тематические кластеры (Cluster)

Группировка по семантической близости с помощью AI:
- Анализ содержимого
- Оценка релевантности (0-100)
- Связывание похожих страниц

**Когда использовать:** Для сложных тематических сайтов.

### 4. Хабовая модель (Hub)

Pillar pages + поддерживающий контент:
- Основные страницы (pillar) получают больше ссылок
- Вспомогательные страницы ссылаются на pillar

**Когда использовать:** Для информационных порталов.

### 5. AI Автоматический (AI Auto)

AI анализирует и выбирает оптимальную стратегию для каждой страницы.

**Когда использовать:** Когда не уверены в выборе стратегии.

## SEO правила

Плагин автоматически применяет следующие правила:

### ✅ Обязательные проверки
- Релевантность контента (TF-IDF + AI scoring)
- Естественное распределение анкоров (≤30% exact match)
- Контроль переспама (плотность ключей < 3%)
- Приоритет dofollow ссылкам на важные страницы
- Учёт PageRank flow
- Избегание каннибализации ключевых слов

### 📏 Константы SEO
```php
AIL_MAX_KEYWORD_DENSITY = 3        // Макс плотность ключей %
AIL_MIN_WORDS_BETWEEN_LINKS = 100  // Мин слов между ссылками
AIL_EXACT_MATCH_LIMIT = 30         // Лимит exact match %
AIL_NOFOLLOW_THRESHOLD = 5         // Порог для nofollow
```

## База данных

Плагин создает 4 таблицы:

### 1. `wp_ai_interlinking_keywords`
Хранит ключевые слова для перелинковки.

### 2. `wp_ai_interlinking_links`
Хранит созданные внутренние ссылки.

### 3. `wp_ai_interlinking_logs`
Логи всех операций и API запросов.

### 4. `wp_ai_interlinking_settings`
Настройки плагина (по языкам).

## API использование и стоимость

### Расчет токенов

- GPT-3.5 Turbo: ~$0.0015 за 1K токенов
- GPT-4: ~$0.03 за 1K токенов
- GPT-4 Turbo: ~$0.01 за 1K токенов

### Примерные расходы

**Генерация ключевых слов:**
- 1 страница ≈ 300-500 токенов
- 100 страниц ≈ $0.05-0.15 (GPT-3.5)

**Анализ релевантности:**
- 1 сравнение ≈ 100-200 токенов
- 100 сравнений ≈ $0.02-0.03 (GPT-3.5)

### Оптимизация расходов

1. Используйте кеширование (включено по умолчанию)
2. Выбирайте GPT-3.5 Turbo для массовых операций
3. Настройте `max_tokens` на разумное значение (500)
4. Запускайте обработку по расписанию в ночное время

## Хуки и фильтры

### Action хуки

```php

// После создания ссылок
```


## Troubleshooting

### API ошибки

**"Invalid API key"**
- Проверьте правильность ключа
- Убедитесь, что у вас есть кредиты на счету OpenAI

**"Rate limit exceeded"**
- Увеличьте `batch_delay` в настройках
- Уменьшите `batch_size`

### Проблемы с производительностью

**Медленная обработка**
- Уменьшите `batch_size`
- Используйте планировщик для фоновой обработки
- Включите кеширование

**Таймауты**
- Увеличьте `api_timeout` в настройках
- Проверьте соединение с интернетом

### Ссылки не создаются

**Проверьте:**
1. Минимальную длину контента (`min_content_length`)
2. Исключенные страницы и категории
3. Наличие ключевых слов
4. Логи операций (AI Interlinking → Logs)
